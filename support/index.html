Pre-launch support

How can we help?

Material Studio is still in development. GitHub Issues will be used temporarily for project and documentation questions.

  1. 01 — Check Review the documentation and current development status first.
  2. 02 — Describe Explain the question or problem clearly, including the affected page.
  3. 03 — Include Add relevant screenshots, browser details, and Shopify store URL when appropriate.
  4. 04 — Submit Open a GitHub Issue in the temporary documentation repository.

Open a support request

Before Theme Store submission, this temporary channel will be replaced by a dedicated merchant contact form on the final custom domain.

Response expectations

This page does not yet represent the final commercial support policy. The final policy, response times, file-upload flow, and autoresponder will be published before the theme is submitted or sold.
