Development version
Material Studio is still in development. Installation files and production support are not yet available.

About the theme

Material Studio is intended for merchants selling architectural lighting, designer hardware, surfaces, fixtures, and interior objects. Its signature experience connects materials, rooms, specifications, products, and sample ordering.

Planned setup areas

  • Brand colors, typography, logo, and favicon.
  • Header navigation for products, materials, rooms, projects, and trade.
  • Material-first homepage sections.
  • Room studies with linked Shopify products.
  • Specification-aware product cards and product pages.
  • Normal Shopify sample products and collections.
  • Collection filters, search, cart, journal, contact, and required templates.

Planned compatibility

The theme is being built for Shopify Online Store 2.0 with sections everywhere, app blocks, Custom Liquid, localization, responsive media, native filtering, product variants, selling plans, pickup availability, and progressive enhancement.

Frequently asked questions

Can I install Material Studio now?

No. The theme has an approved concept and implementation plan, but the production theme has not been released.

Does the theme require an app?

No required app is planned. Standard storefront behavior will work with native Shopify resources. Optional apps may use supported app blocks.

Are metafields required?

No required metafield namespace is planned. Optional dynamic sources may enhance specifications without blocking the base experience.

How will sample ordering work?

Samples will be normal Shopify products or collections. The theme will not provide or imitate a separate fulfillment service.

Where can I follow development?

The public GitHub repository will contain this documentation site. Theme source availability will be decided separately.
